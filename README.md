# Margin

A reading buddy. Keep your library, your notes and the lines you underlined,
and have a conversation with the book while you read it.

- `docs/SPEC.md`: what Margin is and how it works
- `docs/PLAN.md`: the order it gets built in
- `docs/DESIGN-DIRECTION.md`: what it looks like and how it moves

Status: Phase 0 in progress. The Fair catalog design is built on sample data
across the Desk, Shelves, Book page, Buddy and Drawer. There is no backend yet.

```
npm install
npm run dev       # compare cover treatments at /thumbs
npm run build     # typecheck, then production build
npm run lint
npm test
```
