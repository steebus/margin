# Topics, timelines, explore and the buddy's links: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Topics from Hardcover's book tags and Steve's note tags, each with a timeline page, a browsable graph at
`/explore`, tagged notes synced with Hardcover, and a buddy that brings up links on its own.

**Architecture:** Topics are derived, not stored: a pure module (`convex/lib/topics.ts`) turns works' Hardcover tags,
entries' tags and entry text into topic→book and topic→entry links. Convex queries in `convex/topics.ts` run it per
user; the only stored topic state is which topics Steve hid. The graph is a canvas drawn from a d3-force layout.

**Tech Stack:** Convex, React 19, TanStack Router, Vitest + convex-test, d3-force (new: Barnes–Hut keeps ~1,000 nodes
smooth on a phone, which a hand-written O(n²) layout won't).

**Spec:** `docs/superpowers/specs/2026-11-04-topics-design.md`

## Global Constraints

- Books always show at 2:3.
- UI in `src/components/<object>/`, tested logic in `src/lib/` or `convex/lib/`, tokens in `src/styles/tokens.css`.
- Never edit `src/routeTree.gen.ts` by hand. No two `src/` names differing only by case.
- Tests stub `fetch`; nothing writes to the real Hardcover API.
- Reserved labels: `Theme`, `Chapter summary`, `why choose`.
- Hardcover `Tag` kept when `count >= 2` or its name is already a topic; at most 8 per book. `Mood` and
  `Content Warning` ignored. Genres: all of them (Hardcover gives few).
- A mention is the topic name as a whole word or phrase, case-insensitive, or that plus `s`.
- Hiding always wins. Thin topics (one book) stay off the whole-library graph.
- Buddy: at most one unprompted link per reply.
- Check with `npm run build`, `npm run lint`, `npm test`.

## Review Focus

1. A topic name with regex characters ("C++", "Sci-Fi (Hard)") must match mentions literally, not crash or over-match.
2. "Feminism" and "feminism " and "Feminism." from different books are one topic with one slug.
3. A reserved label typed in any case ("theme") stays a label, never a topic.
4. A topic slug that matches nothing (renamed or hidden) shows a plain "nothing here" page, not a crash.
5. A journal pulled from Hardcover with tags must update tags on an entry Margin already has, without re-sending it.

### Task 1: The topic rules (`convex/lib/topics.ts`)

**Files:** Create `convex/lib/topics.ts`, `convex/lib/topics.test.ts`

**Produces:**
- `RESERVED: readonly string[]` and `isReserved(tag: string): boolean`
- `topicKey(name: string): string`: lowercase, trimmed, punctuation stripped, whitespace collapsed; `slugify` of it is the slug
- `bookTags(cached: CachedTags | null | undefined, known?: Set<string>): { name: string; kind: 'genre' | 'tag' }[]`
- `mentions(text: string, name: string): boolean`
- `buildTopics(input: { works: WorkIn[]; entries: EntryIn[]; hidden: Set<string> }): Topic[]` where
  `WorkIn = { readId, slug, title, authors, status, startedAt?, finishedAt?, coverUrl?, artSmallUrl?, tags }`,
  `EntryIn = { id, readId, kind, text, tags, page?, createdAt }`,
  `Topic = { key, slug, name, books: { readId, reasons: Reason[] }[], entries: { id, how: 'tagged' | 'mentions' }[] }`,
  `Reason = { kind: 'genre' | 'tag' | 'note' | 'mentions'; page?: number }`. Hidden keys are dropped.

- [ ] Tests: `topicKey('Feminism.') === topicKey(' feminism')`; `isReserved('theme')`; `bookTags` keeps all Genres,

  `mentions('feministic', 'feminism')` false, `mentions('I like C++ a lot', 'C++')` true; `buildTopics` merges case
  variants, puts a note-tag topic's book in with reason `note` and the page, adds a mentioning entry's book with
  `mentions`, never makes reserved labels topics, drops hidden.

### Task 3: Topic queries (`convex/topics.ts`)

**Consumes:** Task 1, Task 2. **Produces:**
- `topics.list()` → `{ slug, name, books, notes }[]`, visible, most books first
- `topics.page({ slug })` → `null | { name, slug, hidden, items: TimelineItem[], tbr: BookCard[], books: BookCard[], years: [number, number] | null }`
  where `TimelineItem = { kind: 'book', at: number | null, book: BookCard } | { kind: 'entry', at, id, entryKind, text, where, how }`
- `topics.forBook({ readId })` → `{ slug, name }[]`
- `topics.graph()` → `{ nodes: { id, kind: 'topic' | 'book', label, slug, size }[], links: { source, target }[] }`
  (topics with ≥2 books; their books)
- `topics.hide({ slug })`, `topics.unhide({ key })`, `topics.hidden()`, `topics.tagNames()` (all tags used + topic names, reserved first, with `hidden` flag)
- Timeline: read/reading/paused/dnf books at `finishedAt ?? startedAt`, undated at the end; TBR in `tbr`.
- [ ] convex-test: a work tagged Feminism + a note mentioning it on another book → page has both books and the note,
  newest first; hide removes it from `list` and `graph`; unknown slug → `null`. Commit.
