# Kobo pull Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kobo highlights and notes arrive in Margin (and Hardcover) from a button and a daily pull; the Kobo book
list arrives from a bookmarklet.

**Architecture:** Kobo's library page is behind bot protection for servers (403 "Challenged", 2026-11-04), but the
annotations endpoint answers a server holding the cookie. So the book list is read in Steve's browser by a bookmarklet
on My Books, which hands it to a Margin page in the URL fragment; that page matches books, adds missing ones and stores
each read's Kobo id, the way the Audible import works. The server then pulls annotations for every read with a Kobo id.

**Tech Stack:** Convex (actions, crons, convex-test), React, TanStack Router, vitest.

**Spec:** `docs/superpowers/specs/2026-11-04-kobo-pull-design.md` (see its "Change after building began").

## Global Constraints

- Convex production only; tests stub `fetch`, never call Kobo or Hardcover.
- Fixtures are made up, never Steve's real library or cookie. Never print the cookie.
- Requests to Kobo send `user-agent: margin/1.0`; about 1 s between requests; stop on the first 401/403.
- Status only moves forward; finished-on-Kobo marks read undated; nothing is half-written on a shape change.

## Review Focus

- A cookie that has expired: the pull records "Kobo needs signing in again" and writes nothing.
- A pull run twice: no new entries, no new Hardcover outbox rows.
- An annotation with a note but no highlighted text: kept as a plain note, not dropped.
- An entry saved on a book Hardcover hasn't linked yet: sent once the book is linked.
- A Kobo book whose Hardcover top hit is a different book: offered for a choice, never added blind.

### Task 1: Pure Kobo parsing and the shared book match

**Files:** Create `convex/lib/kobo.ts`, `convex/lib/kobo.test.ts`, `convex/lib/match.ts`; modify `src/lib/audible.ts`.

**Produces:**
- `sameBook(a: { title: string; author: string }, b: { title: string; author: string }): boolean` in
  `convex/lib/match.ts` — main title equal and author surname equal (empty author on either side matches any);
  the first author before a comma counts. `planAudible` uses it.
- `koboStatus(text: string): { status: 'read' | 'reading' | 'tbr'; percent: number } | null` —
  `FINISHED` → read 100, `NN% READ` → reading NN, `UNREAD` → tbr 0.
- `parseAnnotations(json: unknown): KoboNote[]`, `KoboNote = { id: string; text: string; note: string; chapter?: string; percent?: number }`;
  throws `Error('kobo shape')` if `annotations` isn't an array or an item lacks a string `id`.
- `KoboBook = { koboId: string | null; title: string; author: string; statusText: string }` (what the bookmarklet sends).

- [ ] Tests: `koboStatus('33% READ')` → `{status:'reading',percent:33}`; `parseAnnotations` keeps chapter and
  `percentageOfBook * 100` rounded to one decimal, keeps a note-only item with `text: ''`, throws on `{}`;
  `sameBook({title:'The Reason I Jump: one boy…',author:'Naoki Higashida, David Mitchell +1'},{title:'The Reason I Jump',author:'Naoki Higashida'})` is true.
- [ ] Implement; audible tests still pass. Commit.

### Task 2: Server: cookie, links, pull, cron, and the Hardcover catch-up

**Files:** Modify `convex/schema.ts`, `convex/hardcover.ts` (`linkRead`), `convex/crons.ts`; create `convex/kobo.ts`, `convex/kobo.test.ts`.

**Schema:** `reads.koboId: v.optional(v.string())`; table `koboLinks { userId, cookie, lastPullAt?, lastError?, lastReport?: { books, highlights } }` index `by_user`.
(A table of its own, because `integrations` is read as Hardcover's by `by_user().first()` in several places.)

**Produces (convex/kobo.ts):**
- `saveCookie({ cookie })`, `forget({})` mutations; `status({})` query →
  `{ connected: boolean; lastPullAt: number | null; lastError: string | null; lastReport: {books:number;highlights:number} | null; linked: number }` (never the cookie).
- `link({ links: { readId, koboId }[] })` mutation, checks ownership.
- `pull({})` action (signed in) and internal `pullAll({})` for the cron, both via `pullFor(ctx, userId)`.
- Entries: excerpt `originKey: 'kobo:' + id`, note `'kobo:' + id + ':note'` (parent = excerpt), origin `kobo`,
  `pos: { percent, chapter }`; each enqueued with `enqueueEntry`. Note-only → a plain note keyed `'kobo:' + id`.
- `nextPageOffsetToken` non-null: save the page, and record "Kobo sent more than one page of notes for <title>" as the error (paging param unknown).
- `linkRead` also enqueues the read's entries that have no `hardcoverJournalId`.
- Cron: daily 05:00 UTC `internal.kobo.pullAll`.

- [ ] Tests (stubbed `fetch`): a pull saves excerpt + attached note with Hardcover outbox rows; a second pull adds nothing; a
  403 records the sign-in error and saves nothing; `status` has no cookie; `link` rejects another user's read;
  `linkRead` enqueues an earlier entry.
- [ ] Implement, `npm test`, commit.

### Task 3: Bookmarklet and the Kobo screen

**Files:** Create `src/lib/kobo.ts` (bookmarklet source), `src/components/settings/KoboImport.tsx`, `src/components/settings/KoboSettings.tsx`;
modify `src/routes/settings.integrations.$provider.tsx`, `src/components/settings/Settings.tsx`.

- `koboBookmarklet(origin: string): string` — on `kobo.com/*/library/books`, reads `li.item-wrapper.book` on this
  page and on `?pageNumber=2..` (fetched, until a page has none, at most 50), then sets
  `location.href = origin + '/settings/integrations/kobo#' + encodeURIComponent(JSON.stringify(books))`. Elsewhere it
  says to open My Books.
- `/settings/integrations/kobo` reads and clears the fragment, then plans like Audible: on the shelves → link, and
  move forward; not on them → Hardcover search; top hit `sameBook` → add as ebook and link; otherwise "Check these",
  each with up to 5 hits to pick from or skip. "Make these changes", then it starts a pull.
- Settings → Kobo: paste the cookie (password field), status line, "Pull from Kobo", the bookmarklet with how to use it.

- [ ] Build, lint, test; check the page renders with a sample fragment locally. Commit and push.
